## Архитектура монорепозитория

```
mt-hack_predictor/
├── AGENTS.md                  # Руководство для AI-агентов
├── CLAUDE.md                  # Перенаправление на AGENTS.md
├── README.md                  # Паспорт проекта и быстрый старт
├── Makefile                   # Команды сборки, тестирования и деплоя
├── docs/                      # Вся документация и база знаний
├── backend/                   # Высокопроизводительный Go-бэкенд (Денис)
│   ├── cmd/server/main.go     # Точка входа HTTP/WS сервера
│   └── internal/              # api, engine, feeder, fleet, mlclient, ndtp, ws
├── frontend/                  # Ситуационный дашборд на React + MapLibre (Кирилл)
│   ├── src/                   # Компоненты, хук useTelemetry, стили
│   └── package.json
├── map-service/               # Автономный тайловый сервис TileServer GL
├── ml/                        # ML-пайплайны и инференс (Миша & Артём)
│   ├── pyproject.toml         # Зависимости uv (CatBoost, PyTorch, SHAP, FastAPI)
│   └── src/                   # features, models, api, schemas, core
└── data/                      # Данные, веса моделей и сабмиты
    ├── sample/                # Эталонный сценарий маршрута м3
    └── submissions/           # Готовые сабмиты (submission_catboost_v1.csv, score 1.0)
```

## Шпаргалка команд запуска (Cheat Sheet)

```bash
# Комплексная проверка сборки Go, Frontend и тестов ML:
make check

# Прямой деплой сборки на облачный сервер (без внешних зависимостей):
make deploy-direct

# Запуск Go-бэкенда (порт :8080):
make backend-run

# Запуск Vite дашборда фронтенда (порт :5173):
make frontend-dev

# Синхронизация ML-зависимостей и запуск инференса (порт :8000):
make ml-sync
make ml-run
```
