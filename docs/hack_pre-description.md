## Предиктор изменений в графике движения городского транспорта

Точное соблюдение графика движения — главная метрика качества наземного пассажирского транспорта.

Разработайте ИИ-систему для раннего прогнозирования изменений в движении транспорта (за 10-15 минут до ее фактического наступления задержки). Система должна непрерывно анализировать потоковые телематические данные (формат NDTP), сопоставлять их с эталонным расписанием, выявлять паттерны сбоев и визуализировать проблемные участки на дашборде диспетчера. Это позволит операторам переходить от реактивного управления (когда транспорт уже опоздал) к проактивному — принимать упреждающие меры.

Ключевые функции будущего решения:
* Анализ потоковых данных: обработка исторических и real-time телематических данных и сопоставление их с расписанием.
* Раннее детектирование: выявление транспортных средств с высокой вероятностью задержки в ближайшие 10-15 минут.
* Диспетчерский BI-дашборд: информативный интерфейс с визуализацией уровня риска на маршрутах.
